# 🚀 QUANTA Intent Engine — macOS Chrome Extension Installation Guide

Welcome to the **QUANTA Real-Time Intent Signal Overlay** extension! This guide will help you install and activate the extension on Google Chrome, Brave, or Microsoft Edge on macOS in less than 60 seconds.

---

## 📦 Step 1: Unzip the Extension Package
1. Double-click `quanta-extension.zip` in your macOS Downloads folder to extract it.
2. You will get a folder named `chrome-extension` containing:
   - `manifest.json`
   - `content.js` & `content.css`
   - `popup.html` & `popup.js`
   - `background.js`

---

## 🛠️ Step 2: Enable Developer Mode in Chrome
1. Open **Google Chrome** (or Brave / Edge).
2. Type `chrome://extensions` into your address bar and press **Enter**.
3. In the top-right corner of the Extensions page, toggle the **Developer mode** switch to **ON**.

---

## ⚡ Step 3: Load the Unpacked Extension
1. Click the **Load unpacked** button in the top-left corner.
2. Select the unzipped `chrome-extension` folder.
3. Click **Select** / **Open**.

---

## 🔥 Step 4: Verify Installation & Real-Time Alerts
1. You will see **QUANTA Intent Signal Overlay** appear in your extension list with a blue `98%` badge.
2. Click the **Puzzle Piece icon** in your Chrome toolbar and pin **QUANTA Intent Engine**.
3. Click the extension icon to view live connection status to `https://quanta.virtusol.com`.
4. Click **Dispatch Test Slack & Overlay Alert** to simulate a live intent ping!
